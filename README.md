Task 1 - Data Cleaning and Preprocessing

Objective
To clean and preprocess a raw dataset by handling missing values, removing duplicates, standardizing data formats, and preparing the dataset for analysis.

Dataset
Netflix Movies and TV Shows Dataset

Tools Used
- Python
- Pandas
- Google Colab

Data Cleaning Steps
1. Loaded the dataset using Pandas.
2. Checked for missing values.
3. Handled missing data appropriately.
4. Removed duplicate records.
5. Standardized column names.
6. Converted date columns to proper format.
7. Verified and corrected data types.
8. Saved the cleaned dataset.

Files Included
- netflix.csv (Original Dataset)
- cleaned_netflix.csv (Cleaned Dataset)
- DataCleaning.ipynb (Google Colab Notebook)
- Screenshots of the cleaning process

Outcome
The dataset was successfully cleaned and prepared for further analysis and visualization.
